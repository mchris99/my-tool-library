# Security Policy

## Supported Versions

Only the latest released version of My Tool Library is supported with security fixes.

## Reporting a Vulnerability

If you find a security issue, please report it privately rather than opening a public GitHub issue. This plugin stores personal member data (contact details, links to member photos and identity-verification documents, and records of signed member agreements), so reports may involve sensitive details.

**Preferred:** use GitHub's [private vulnerability reporting form](https://github.com/mchris99/my-tool-library/security/advisories/new) (also under the repository's **Security** tab, **Report a vulnerability**). Only you and the maintainers can see the report, and we can discuss and fix it there before anything is made public.

**No GitHub account?** Email **info@mkelibrary.org** instead.

Either way, please include:

- A description of the issue and its potential impact
- Steps to reproduce it
- Any relevant logs, screenshots, or proof-of-concept code

Once a fix is released, we'll publish a security advisory describing the issue, and credit you if you'd like. Please allow time for that fix before any public disclosure.
