# Security Policy

## Supported Versions

Only the latest released version of My Tool Library is supported with security fixes.

## Reporting a Vulnerability

If you find a security issue, please report it privately rather than opening a public GitHub issue — this plugin stores personal member data (contact details, and links to identity-verification documents), so reports may involve sensitive details.

To report a vulnerability, email **info@mkelibrary.org** (or the maintainers directly) with:

- A description of the issue and its potential impact
- Steps to reproduce it
- Any relevant logs, screenshots, or proof-of-concept code

Please allow time for a fix to be released before any public disclosure.
